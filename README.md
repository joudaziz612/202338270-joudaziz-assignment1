# Personal Portfolio Website

This is my personal portfolio website created for Assignment 1.

## About the Website

The website introduces me as a Computer Science student and presents some of my projects and interests.

## Projects

### SCC – Smart Solar Cleaning System
A smart solar panel cleaning system designed to reduce dust accumulation on solar panels. It uses a dust sensor to detect when cleaning is needed and automatically activates a cleaning mechanism.

### Plant Care Website
An ongoing web design project that helps users learn about different types of plants and how to care for them, especially under Saudi Arabia's climate conditions. The project also aims to provide access to plant-care consultants.
