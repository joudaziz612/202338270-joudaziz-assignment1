# Technical Documentation

## Project Overview

This project is a responsive personal portfolio website developed using HTML, CSS, and JavaScript. The website introduces me, presents some of my projects, and provides a contact form.

## Technologies Used

- HTML5 for the structure and content of the website.
- CSS3 for styling, layout, responsive design, and Dark/Light Mode.
- JavaScript for website interactivity.
- GitHub for version control and project hosting.
- GitHub Pages for deploying the website.

## Project Structure

- `index.html` – Contains the main structure and content of the portfolio.
- `css/styles.css` – Contains the website styling and responsive design.
- `js/script.js` – Contains the JavaScript functionality for the Dark/Light Mode.
- `assets/images/` – Contains the images used in the Projects section.
- `docs/ai-usage-report.md` – Documents how AI was used during development.
- `docs/technical-documentation.md` – Contains the technical documentation of the project.

## Website Sections

### About Me
Provides a short introduction about me as a Computer Science student.

### Projects
Displays two projects: SCC – Smart Solar Cleaning System and an ongoing Plant Care Website project.

### Contact
Provides a contact form containing Name, Email, and Message fields.

## JavaScript Feature

The website includes a Dark/Light Mode button. When the user clicks the button, JavaScript adds or removes the `dark-mode` CSS class from the page and changes the button text.

## Responsive Design

The website uses responsive CSS to adapt to different screen sizes. A media query is used to improve the layout on smaller screens, such as mobile devices.

## Running the Website Locally

1. Download or clone the GitHub repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional installation is required.

## Deployment

The website is deployed using GitHub Pages from the `main` branch.
